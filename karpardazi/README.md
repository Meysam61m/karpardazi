# سامانه کارپردازی مجتمع خراسان

سامانه ثبت و چاپ «سند هزینه شعبه» — شرکت انبارهای عمومی و خدمات گمرکی ایران (مجتمع خراسان)

## امکانات

- ثبت سند هزینه شعبه با اقلام نامحدود (مبلغ، مالیات، بیمه — ریال)
- تقویم شمسی در همه فرم‌ها و تاریخ‌های شمسی در همه صفحات
- شماره‌گذاری خودکار، یکتا و غیرقابل‌تغییر پس از «ثبت قطعی» (الگو در تنظیمات قابل تغییر است)
- پیش‌نویس → کنترل → ثبت قطعی؛ چاپ فرم A4 دقیقاً مطابق نمونه کاغذی برای امضای حضوری
- هیچ گردش کار تأیید الکترونیکی و هیچ پیوست فایلی در سامانه وجود ندارد
- مدیریت شعب (نام + کد) و کاربران (مدیر / کارپرداز)
- تنخواه هر کارپرداز: مبلغ، تاریخ شارژ و مانده در داشبورد
- داشبورد، گزارش‌های روزانه/ماهانه/سالانه/شرح هزینه/مالیات و بیمه/اسناد ناقص + خروجی Excel
- سوابق کامل تغییرات (کاربر، زمان، مقدار قبل و بعد)
- پشتیبان‌گیری و بازیابی پایگاه داده (در پنل مدیر)
- کاملاً آفلاین: بدون نیاز به اینترنت یا CDN

## نصب روی ویندوز با Laragon (پیشنهادی)

۱. **Laragon Full** را از laragon.org نصب کنید (شامل Apache + PHP 8 + MySQL).
۲. پوشه `karpardazi` را داخل `C:\laragon\www\` کپی کنید.
۳. در Laragon روی **Database** کلیک کنید و یک دیتابیس خالی با نام `karpardazi` بسازید
   (یا در HeidiSQL: ‏`CREATE DATABASE karpardazi CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`)
۴. فایل `.env.example` را به نام `.env` کپی کنید و در صورت نیاز نام/رمز دیتابیس را اصلاح کنید.
۵. ترمینال Laragon را باز کنید (دکمه **Terminal**) و دستورات زیر را اجرا کنید:

```
cd C:\laragon\www\karpardazi
php artisan key:generate
php artisan karpardazi:install
```

دستور آخر جداول را می‌سازد، شعب پیش‌فرض را وارد می‌کند و **به صورت تعاملی** از شما
نام کاربری و رمز عبور مدیر را می‌پرسد (هیچ رمز پیش‌فرضی در برنامه نیست).

۶. در Laragon: منو → **Apache → sites-enabled** — یا ساده‌تر: در مرورگر به آدرس
   `http://localhost/karpardazi/public` بروید.
   برای آدرس تمیزتر، یک Virtual Host با ریشه `C:\laragon\www\karpardazi\public` بسازید
   (در Laragon: Menu → Quick app → … یا ساخت دستی `karpardazi.test`).

۷. برای دسترسی از سایر کامپیوترهای شبکه داخلی، Apache را روی IP سرور باز کنید
   (فایروال ویندوز: پورت 80) و با آدرس `http://IP-SERVER/karpardazi/public` وارد شوید.

## ورود و استفاده

- مدیر: مدیریت کاربران/شعب/تنظیمات/سوابق/پشتیبان + همه امکانات کارپرداز
- کارپرداز: ثبت/ویرایش/چاپ اسناد و گزارش‌ها
- سند ابتدا «پیش‌نویس» ذخیره می‌شود؛ پس از کنترل با دکمه «ثبت قطعی» شماره می‌گیرد.
- ویرایش سند قطعی ممکن است، اما شماره آن تغییر نمی‌کند و همه تغییرات در سوابق ثبت می‌شود.
- **قانون چاپ:** تا «تاریخ شارژ تنخواه» کارپرداز (از بخش مدیریت ← کاربران) ثبت نشده باشد،
  چاپ سند ممکن نیست و پیام راهنما نمایش داده می‌شود.

## پشتیبان‌گیری دستی (جایگزین)

در ترمینال Laragon:

```
mysqldump -u root karpardazi > backup.sql
mysql -u root karpardazi < backup.sql
```

## فناوری‌ها

Laravel 12 · PHP 8.2+ · MySQL/MariaDB · Bootstrap 5 RTL · Vazirmatn ·
persian-datepicker · Chart.js (همه محلی، بدون CDN)


## ارتقا به نسخه جدید

۱. فایل ZIP جدید را باز کنید و **روی پوشه نصب فعلی** کپی کنید (جایگزینی همه فایل‌ها).
   فایل `.env` شما داخل بسته نیست و دست‌نخورده می‌ماند؛ دیتابیس هم تغییر نمی‌کند.
۲. در ترمینال Laragon: `php artisan migrate --force` (اگر تغییری لازم نباشد کاری انجام نمی‌دهد).

## تغییرات نسخه ۱.۱

- رفع خطای «مبلغ تنخواه باید عدد صحیح باشد»: ورودی تنخواه با جداکننده هزارگان و ارقام فارسی پذیرفته می‌شود.
- رفع خطای ۵۰۰ صفحه «اسناد» روی MySQL/MariaDB.
- چاپ سند فقط پس از ثبت «تاریخ شارژ تنخواه» کارپرداز ممکن است.
